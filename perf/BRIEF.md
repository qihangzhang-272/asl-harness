# 加载优化边界

目标：统一编辑实现，减少首屏不需要的旧布局代码；保留功能、原生 Mermaid、校验及浅蓝视觉。

参考：[花叔·闪电](https://github.com/alchaincyf/huashu-flash)。使用测量—护栏—对照方法，不安装或执行远端技能脚本。

用户可用定义：工作库列表可操作；点击模式后实际 SVG 出现。不能以骨架出现或包体减小冒充加载完成。

护栏：Node 核心/边界测试、真实 Electron 创建保存与坏图拒写；不更改真实账号，不增加全量预加载、数据库或后台模型。

范围：Windows，同一 Electron、Python、公开两技能示例库，前端重载；大型库、冷机启动、真实 GitHub 与后台扫描下的长尾点击另外测量。
