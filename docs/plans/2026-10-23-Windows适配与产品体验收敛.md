## 目标与边界

让 Windows 用户能顺畅阅读和管理技能、组织 Mode、看清同步结果和 Agent 会话状态，并容易下载、打开新版。保留 Mac 已完成的中性视觉，不另建 Windows 主题或调度器。

- 不改真实 Skill、Mode、账号、投影与私人归档；所有写入验收使用隔离样例。
- GitHub 已提交版本仍是跨机共享基线；本地草稿不覆盖、不自动上传。
- 前端主设计使用 Impeccable 4.5.2，工程遵循本地原版 Ponytail v5.1.0，沿用已有模块、CLI 与设计规范。
- “立即反馈”与“写入成功”分开；会话打开、会话结束与任务结果验证分开，不猜测 Agent 是否正在思考或等待输入。
- 已有旧写作目标处于阻塞，不能冒充完成后重设；本轮由本计划和临时接续自动化 `asl-windows` 保证接续，不恢复旧实验。

## 顺序及成功标准

1. **Windows 渲染与交付底座**：复现默认渲染器退出，做单变量定位，保留合法／非法 Mermaid 的真实写入门控。源码默认路径与最终冻结包都通过后才称修复。
2. **阅读与采用**：落实[已批准的阅读方案](2026-10-23-source-reading-and-mode-adoption.md)。README、作者语言版本和配套文件留在 App；区分预览位置、最初来源与本机使用位置；加入 Mode 的草稿与保存反馈一致。
3. **同步与会话反馈**：DeepSeek 写入完成后立即刷新 App 内事实；原生新会话生效要求说清楚。Codex／Claude Code 仅展示本 App 发起会话的可核实状态，不扫描私人对话、不擅自调用模型。
4. **视觉与打包**：统一既有 Mac 留白、排版、列表、菜单及反馈；一次批量实机观察与一轮修正。Windows 下载解压后可运行、可找到入口；不伪称已签名安装器或 Mac 原生验收。
5. **最终交付**：精确审查差异，复核远端新提交；仅提交本轮框架／App／CLI／入口文档，中文带日期时间。最终包验收通过再推送、发布、正常更新桌面并打开；保留旧版与设置，不强制关闭未保存窗口。
