# Trace 时间轴视觉与连续性

范围：仅调整演变页的呈现与动效，保留 Apple 风格、原版本数据、说明写入和恢复流程；按用户后续要求移除播放控件及自动回放。不改 Mode／Mermaid 文档、关系稿或候选／试用机制；不提交、推送或替换发行包。

## 方案与取舍

- 采用连续版本轨道：每个版本一个固定间距节点，节点、拖动刻度和标题共用位置；选中节点平滑进入视野。版本等距表示先后顺序，不暗示实际时间间隔。
- 纵向记录列表便于读长说明，但会抢占画板空间；缩略图卡片会重复渲染图并增加负担。本轮均不增加。
- 画板和依据共用一块阅读表面，时间轴只保留版本识别与直接选择；完整原因在右侧阅读，窄窗口按需展开。

## 动效与节点逻辑

焦点：同一条轨道上的选中游标自然减速移动。拖动时立即跟手，松手／点击／键盘时保持所选节点可见，不整排重建附近节点。滚动浏览不改变正在读的版本；拖动刻度或点击节点才切换，原生方向键逐版选择。

连续性：仅在同一个架构视图内按作者节点身份衔接；已有节点移动，新增／文字变化节点给蓝色提示。跨图类型及未知身份仅淡入，不猜对应。第一帧不把所有节点当新增。尊重减少动态效果。

预算：复用 React、CSS 和 Web Animations；不新增组件库。单次常规动效约 200–280ms，不能阻塞版本读取或操作。连续切换保留现有单任务渲染与过期响应守卫。

## 验证计划

1. 节点语义与跨视图动效 → 小型回归确认首次不误报、新增／改名可辨、跨视图不移动猜测。
2. 轨道与说明呈现 → 原生窗口检查刻度对齐、长标题、多版本滚动、键盘／拖动／滚动浏览、说明同版本、减少动态效果。
3. 保留写入边界 → 既有说明冲突／恢复专项及相关模块回归；宽窄窗口一轮检查、集中修正、最多一轮复核，运行 Impeccable 检测。

## 本轮参考与用户补充

用户明确要求移除播放键及对应逻辑，交互应通过滚动、拖动和选择体现。采用直接操作轨道的方向，删除定时回放状态与整组媒体式控制，不隐藏保留旧逻辑。

- [Final Cut：Skim media](https://support.apple.com/guide/final-cut-pro/skim-media-vere9ba3609/mac)：位置直接对应预览；本 App 用按住拖动或点击表示意图，不采用悬停就切换。
- [Figma：Version history](https://help.figma.com/hc/en-us/articles/360038006754-View-a-file-s-version-history)：主题、日期与说明帮助定位，选中版本在画布中查看，恢复是单独操作。
- [Photos：Keyboard shortcuts and gestures](https://support.apple.com/guide/photos/keyboard-shortcuts-and-gestures-pht9b4411b24/mac)：保留原生方向键浏览。

参考交互原则，不复制第三方代码或新增组件依赖。
