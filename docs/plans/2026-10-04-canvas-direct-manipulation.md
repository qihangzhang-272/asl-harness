# 画板直接操作补齐计划

依据：用户实测 0.5.10 后反馈节点无法移动、端口不吸附、连线删除不明确。本计划接续鼠标优先计划，纠正把结构排序当成自由拖动的验收缺口。

## 已复现与范围

- 公司画像拖动 70×80 像素，移动前、中、后屏幕位置完全相同；现有实现只调整声明顺序，空白落点不生效。
- 四面端口只传递节点 ID，丢弃所选侧；预览只跟鼠标，不做近点吸附。
- 当前发行的平行连线右键可以出现“移除”。继续用真实指针检查命中、重叠及保存状态，不把未复现情况写成确定根因。
- 只修 Harness 的流程图画板及隔离测试；不修改真实 Skill 或 Mode，不扩大为任意图型自由坐标。时序和思维图仍遵循其结构语义。

## 简单实现

原生 Mermaid 继续决定初始图形、风格和布局。流程图的交互层直接移动已有 SVG 节点、更新相连路径。连接关系始终保留标准 Mermaid；手工位置与端口作为同一代码块中的 `%% asl-layout` JSON 注释保存，不另设文件、坐标数据库或调度层。普通阅读器忽略该注释并自动排版；ASL 读取后恢复手工布局。注释只允许已存在节点／连线、有限坐标和四种端口；错误交给已有渲染门控拒绝。删除节点或边同步清理对应布局记录。

## 顺序与验收

1. 先补回归：实际鼠标拖动、缩放坐标、上对上吸附、平行边精确删除、取消及写入失败不残留。
2. 补原生 SVG 交互：跟手移动和连线路由、屏幕距离吸附及高亮，右键明确“删除连线”，不新增常驻按钮。
3. 验证同一 Mermaid 原文往返：保存重开位置／端口不丢失，重命名及增删不误改其他边，坏注释和坏图拒绝。保留撤销／重做路径。
4. 运行相关及完整前端回归、真实 Electron 鼠标操作和既有图型回归；更新专项视图，区分开发验证与正式发布。真实内容库只做读取与摘要检查。

- 四步实现与候选验收已完成。Node 186 项通过；最终候选 EXE 桌面 14 项通过，直接操作证据 `%TEMP%/asl-direct-canvas-CulKCp/asl-e2e-YuQcMP`，整体日志 `%TEMP%/asl-0.5.11-e2e-final6.log`。
- 独立复审先后复现同向平行线及反向线重合、命中后删错边；共享路由按端点对分离通道后，实际指针分别删除正反向边复验通过。证据 `%TEMP%/asl-review-reverse-fixed-F9F6Yo/asl-e2e-SY1WZ2`。原失败保留，不用“菜单存在”代替可用性验收。
- 节点实时跟手、缩放换算、保存不跳位、上对上吸附、多侧连接、平行边精确命中、重开还原、取消与只读写入失败回滚均覆盖。坏布局经冻结 CLI 实际渲染门控拒绝，不写原文。
