# Mermaid 画板交互收束

> 历史计划。后续交互只维护[鼠标优先画板计划](2026-10-04-mouse-first-mermaid.md)，本文保留追溯，不再追加待办。

用户已明确操作路径，保留浅蓝视觉和原生 Mermaid 清晰度。

1. 画板内操作：移除常驻添加下拉框。空白处右键打开可搜索技能选择；节点右键提供查看、改名、连接、移出，连线提供改备注与删除。连接点允许拖动，Esc 取消。
2. 技能阅读：单击技能节点打开主区域完整文件；同一张图收缩后悬浮到右上层，与正文保持重叠，仍能切换节点，不分成互斥页面、不预留整行空白。点击“技能逻辑架构”恢复居中的完整画板。双击节点原位改字；文档和脚本继续使用现有文件编辑与保存门禁。
3. 同源写入：图修改仍保存到 MODE.md；增加成员同时提交技能根与所属范式。复用已有本机发现缓存、来源去重和 CLI 导入校验，不建立第二份图模型。原生其他图型继续完整渲染和原文编辑。
4. 验收：在真实技能库的隔离副本测试右键添加、搜索、节点与连线修改、拖动连接与取消、技能切换及返回、未保存保护、保存后重开和窄窗。核对图与 CLI 回读一致，并更新总体状态和 App 专项视图。
5. 补充链路：同仓库语言与 Markdown 链接留在 App；已连接仓库独立于本地 Mode 来源显示；预读与点击共享在途请求。安装后可选运行检查只联系目标宿主，不另选配置者。Mode 说明使用直接表述，保留实际授权边界。

当前验收与尚未交付的边界只维护在 [总体状态 View 9](../asl-architecture-views.md#view-9--当前项目状态)，不在本计划重复完成数字。

交互参考：[Apple 上下文菜单](https://developer.apple.com/design/human-interface-guidelines/context-menus)、[tldraw 连接控制点](https://tldraw.dev/sdk-features/handles)。采用其就地操作方式，继续使用现有 Mermaid 渲染和 CLI。
