# DSH 技能预览与执行产物

用户已确认先实现节点单击预览、真实执行进度、产物预览及基本目录操作。保持既有 Mode 和 Mermaid 关系，视觉由 Stitch 提供。

1. 预览与目录：单击节点保持画板，预览一至两个绑定技能。快速预览与完整编辑页共用目录组件，支持展开收起、键盘、右键、复制路径、系统定位和完整页编辑。验证快速切换不串文件、不丢草稿，保留双击改名及拖拽。
2. 运行与产物：读取 DSH 当前会话的实际工具事件和状态，不从画板选中推断执行、不编造百分比。产物必须存在，绑定会话及实际路径；使用 Sidebar 原有文件预览能力，插件内保留可用的阅读入口。验证失败写入不成为产物、跨会话不串、外部路径及链接越界被拒绝。
3. 联调交付：使用隔离环境与官方 DSH 实际加载、文件读写和目录定位接口验证。视觉 CSS 来自 Stitch，截图展示实际运行界面；桌面工具故障与原生窗口验收缺口单独报告。

范围不含重写技能内容、改变 Mode 架构、额外 Agent 引擎、团队调度器或自动发布业务内容。运行反馈复用宿主事件，不增加第二份执行日志。


## 用户补充与实现

沿用已经确认的浅色 Google 视觉，Stitch 只能参考现有稿，不自由重设计。新增 CSS 来自 Stitch `1e17b76ca5354ecfb105d0b18fbe3ac4`；轻量编辑来自 `0e58a20d77304921956db4d1cdb293b9`，共享 stitch-theme.css 保持原样。用户随后明确预览展开后也需要直接编辑，因此预览支持 Markdown 原文、阅读切换、Ctrl/Cmd+S 与草稿保护。

单击预览与完整编辑页共用 FileTree。预览编辑沿用原有 save/fingerprint 入口；进入编辑后将该技能文件作为当前会话的目标。只读 inspection 不授权写技能。宿主事件投影位于 execution.cjs，不创建额外执行数据库。

Sidebar 联动先打开同一原生会话，订阅 sidebarRight.mounted，挂载后才发文件地址，避免 no session surface is mounted。画板尺寸改变时，只平移镜头确保所选节点可见，不降低阅读缩放或修改 Mode。
