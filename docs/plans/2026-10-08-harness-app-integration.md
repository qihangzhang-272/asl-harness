## 目标与边界

先修复已确认的读取、配置和重复加载问题，再把已有工作偏好及反馈记录接入 App。复用现有 CLI、文件、校验与界面；不新增调度器、数据库或模型服务。保持浅蓝视觉与原位操作，未保存内容离开前确认。

仅修改 Harness / App、隔离测试及架构文档。真实 Skill、Mode、账号与宿主投影不动；其他 Agent 的既有修改保留。功能完成、开发验收、桌面交付分别记录。本轮不把新功能建议、更多宿主、自动培养或模型配置中心默认为已完成。

技术沿用 Python CLI、Electron、React、原生 Mermaid。使用 Ponytail 收束实现，Impeccable 检查既有交互；不创建第二份实现。

### 已完成的实现

1. **只读隔离：**新增显式只读加载模式，只向目录与文件阅读调用开放；坏条目以结构化 `issues` 返回，有效 Mode 可继续打开。关联坏 Skill 的 Mode 不冒充正常；链接、Secret、路径约束保留。正式写入、导出、宿主投影仍严格校验。
2. **配置结果：**WorkBuddy 给出自己的操作指引；运行要求同时读取 SKILL 与 SOURCE。保留告警、冲突定位和实际配置位置，技术详情默认折叠；检查异常可重试。Hook 区分项目、DeepSeek 模式与未覆盖范围，命令存在不等于真实触发通过。运行说明回到对应库内文件，不跳错同名技能。

5. **复审修复：**覆盖 A→B→A 刷新后再读／重开、同仓库地址别名离线重开、刷新请求不被进行中的缓存读取吞掉；没有添加第二索引或请求服务。
